# Project instructions

- This is a personal, non-Avito project. Avito/RAR branch and commit naming rules do not apply.
- Direct commits, pushes, and merges to `main` are explicitly allowed by the repository owner.
- Pull requests are optional; do not add reviewers unless explicitly requested.
- Keep the deployment single-user and simple: one server container plus one SQLite volume.
- Preserve the manual iOS synchronization flow and support free Apple Personal Team signing.
